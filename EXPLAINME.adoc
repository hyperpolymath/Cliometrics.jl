== README Claims — Verified

=== Claim 1: "Growth Accounting — decompose economic growth into capital, labour, and TFP contributions"

*True.* `src/Cliometrics.jl` exports `solow_residual/3` and `decompose_growth/2`.
`solow_residual` takes output, capital, and labour series and computes the
Solow residual (total factor productivity growth) using the standard growth
accounting identity: `TFP = Y_growth - α·K_growth - (1-α)·L_growth` where
`alpha` defaults to 0.3 (capital share). `decompose_growth` returns a
`DataFrame` with columns `output_growth`, `capital_contribution`,
`labor_contribution`, and `tfp_contribution`.

The test suite verifies these against known values: for a 5% geometric growth
rate, the log-difference calculation is tested to `atol=1e-6`.

*Caveat:* The Solow residual is a measure-of-ignorance residual; it conflates
technological change, efficiency improvements, and model misspecification.
The package does not decompose TFP further.

=== Claim 2: "Historical data loading with date parsing and year filtering"

*True.* `load_historical_data/2` reads CSV files using `CSV.jl` and `DataFrames.jl`,
parses year columns via `Dates.jl`, and accepts `start_year`/`end_year` keyword
arguments for range filtering. `clean_historical_series` handles missing values
and outliers. `interpolate_missing_years` fills gaps in irregular time series.

*Caveat:* The package assumes input CSVs follow a convention where the year
column is named `year` (or is detectable by date format). Non-standard column
names require the caller to rename before passing to `load_historical_data`.

=== Claim 3: "Counterfactual Historical Modeling — estimate treatment effects for historical interventions"

*True.* `counterfactual_scenario/3` and `estimate_treatment_effect/3` implement
a difference-in-differences style estimator for historical interventions (e.g.,
"what if the Black Death had not occurred?"). The functions accept a control
series, a treatment series, and an intervention year, returning estimated
counterfactual trajectories and ATEs.

*Caveat:* The counterfactual estimator is a reduced-form statistical method,
not a structural model. It assumes parallel pre-trends and does not account for
general equilibrium effects.

== How It Works

The package is a `DataFrames`-first toolkit. Almost every function accepts and
returns `DataFrame` objects, making it composable with the broader Julia data
ecosystem. The internal pipeline follows:

. Load raw historical data via `load_historical_data` (CSV → DataFrame with
  standardised column names)
. Clean and interpolate via `clean_historical_series` / `interpolate_missing_years`
. Compute growth rates via `calculate_growth_rates` (`:geometric` or `:arithmetic`
  method keyword)
. Decompose via `decompose_growth` (Solow residual accounting)
. Analyse convergence via `convergence_analysis` (beta and sigma convergence tests)
. Quantify institutional quality via `quantify_institutions` /
  `institutional_quality_index`
. Run counterfactuals via `counterfactual_scenario` / `estimate_treatment_effect`

The `coprocessors/` directory in `src/` contains specialised backends (crypto,
dsp, fpga, math, npu, ppu, qpu, tpu, vpu) for future acceleration of
computationally intensive operations via the AcceleratorGate pattern.

== Honest Caveats

* Package is at 85% completion (TOPOLOGY.md). Panel data econometrics
  (fixed/random effects, instrumental variables) are in the roadmap but
  not yet implemented.
* `institutional_quality_index` uses a simple weighted-average of input
  indicator columns; it does not implement Acemoglu/Robinson-style
  structural institutional metrics.
* The AcceleratorGate GPU weak-deps (CUDA, AMDGPU, CryptoAccel, DSPLibs)
  in `Project.toml` are scaffolded; no GPU-accelerated paths are operative.
* There is no built-in historical dataset; callers must supply their own
  CSV files (e.g., Maddison Project, Penn World Tables).
